Meaning of Queue
A queue is a linear data structure that follows the FIFO principle, which means First In, First Out.
This means that the first element added to the queue is the first element to be removed.

Algorithm for Implementing a Queue
Step 1: Start.
Step 2: Declare an array called QUEUE with a maximum size of 5.
Step 3: Initialize FRONT = -1 and REAR = -1.
Step 4: Display the available queue operations.
Step 5: If the user selects ENQUEUE:
- Check if the queue is full.
- If full, display "Queue Overflow".
- Otherwise, insert the new element at the REAR position.
- Update FRONT and REAR where necessary.
Step 6: If the user selects DEQUEUE:
- Check if the queue is empty.
- If empty, display "Queue Underflow".
- Otherwise, remove the element at FRONT.
- Update FRONT and REAR.
Step 7: If the user selects PEEK:
- Display the element at the FRONT position.
Step 8: If the user selects DISPLAY:
- Display all elements from FRONT to REAR.
Step 9: If the user selects EXIT, terminate the program.
Step 10: Stop.
