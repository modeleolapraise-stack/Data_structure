Assignment 1: Stack Applications and Array Operations

Meaning of Stack
A stack is a linear data structure in which elements are added and removed from only one end, called the TOP. It follows the LIFO principle, which means Last In, First Out. This means that the last element added to the stack is the first element to be removed.
Real-Life Applications of Stack
1. Web Browser History: When browsing the internet, the pages visited are stored in a stack. When a user clicks the back button, the browser returns to the most recently visited page.
2. Undo and Redo Operations: Applications such as Microsoft Word use stacks to keep track of changes made to a document. The undo operation reverses the most recent action, while redo restores an undone action.
3. Call Stack in Programming: Programming languages use a call stack to manage function calls. When a function is called, it is placed on the stack and removed when its execution is completed.
4. Text Editors: Text editors use stacks to manage typing actions, allowing users to undo or redo their previous activities.
5. Expression Evaluation: Compilers and calculators use stacks to evaluate mathematical expressions and manage operators and operands.
6. Reversing Data: Stacks can be used to reverse words, numbers, or strings because the last item entered is the first one retrieved.
